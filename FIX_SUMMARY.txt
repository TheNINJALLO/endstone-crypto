ISSUE IDENTIFIED
================================================================================

When the Crypto plugin was installed, PrimeBDS failed to load with:
  ModuleNotFoundError: No module named 'endstone.util'

ROOT CAUSE
================================================================================

The Crypto plugin had a loose dependency constraint:
  dependencies = ["endstone==0.10"]

This allowed installation of ANY Endstone 0.10.x version, including older
versions (0.10.0-0.10.6) that don't have the endstone.util module.

PrimeBDS requires endstone.util.Vector, which was added in Endstone 0.10.7.

SOLUTION APPLIED
================================================================================

Updated the dependency constraint to require the minimum version that has
endstone.util:

  OLD: dependencies = ["endstone==0.10"]
  NEW: dependencies = ["endstone>=0.10.7"]

✅ Fixes PrimeBDS compatibility
